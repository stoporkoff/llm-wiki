# Contributing

Thank you for improving LLM Wiki.

1. Open an issue describing the behavior or design change.
2. Keep changes focused and preserve the file-workspace contract.
3. Add or update tests for observable behavior.
4. Run `pytest`, `ruff check .`, and `mypy src`.
5. Do not include secrets, private sources, generated wiki data, or model transcripts.
